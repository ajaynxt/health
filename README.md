# Velora Health Institute Demo

Original fictional multi-speciality hospital and diagnostics website created for the AJAYNXT portfolio.

## Included

- Original healthcare SVG logo
- Cinematic hospital hero
- Doctor, speciality and location search
- Appointment booking flow
- Emergency-information warning without a fake hotline
- Department filters
- Doctor search, filters and profile modal
- Preventive health-check packages
- Diagnostics and secure-report portal concept
- Patient journey
- Hospital-location search
- International-patient section
- Insurance guidance
- AJAYNXT website-price form
- Auto colour and heading-font changes every 3 seconds
- Manual colour picker, HEX and font selector
- Colour lock, font lock and lock both
- Light, dark and system modes
- Responsive/mobile actions
- SEO, JSON-LD, sitemap, robots, manifest, favicon, 404 and CNAME

## GitHub Pages

1. Upload all files to repository root.
2. Open Settings → Pages.
3. Choose Deploy from a branch.
4. Select `main` and `/root`.
5. Save.
6. Set custom domain to `health.ajaynxt.com`.

## DNS

- Type: CNAME
- Name: health
- Value: ajaynxt.github.io
- TTL: default or 30 minutes
